Past Work

Programming and software

  • YipLoader 2026 - present
    Yip Loader is a fork of KnShim designed to be a generic mod loader for any game.
  • KnShim 2024 - 2026
    KnShim exposes various utilities to scripts in mobile games by Mediocre AB.
  • Leaf 2024 - present
    Leaf is a single header ELF loader and function hooker designed for modding Android games.
  • Katten Server 2023 - present
    Katten Server is a reimplementation of the server for the games Touch Pets Cats and Touch Pets Dogs 2.
  • Smash Hit Lab Website 2023 - 2024
    The Smash Hit Lab website was a database of mods combined with a news section and user forums.
  • Marmalade Modding 2022
    Research around modding games made with the Marmalade SDK by IdeaWorks.
  • Stratigise 2022 - 2024
    Research and decompiler of Croc: Legend of the Gobbo's script ("strategy") bytecode.
  • Shatter 2020 - 2025
    Level editor for the mobile game Smash Hit, made in Blender.
  • Melon 2021 - 2023
    Simple core library used in some of my older games.
  • Quick Run 2021
    My first attempt at making a game and game engine. Cancelled, unfortunately!
