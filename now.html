  • I reinstalled Arch Linux (okay well, moved from the Manjaro-turned-to-Arch to proper Arch), granted I used archinstall which I've made the decision to never use again.   • And oh god, did I ever struggle to get WiFi working. It technically worked, but it would constantly cut out every few minutes and was generally unacceptable for playing Minecraft, which doesn't handle disconnections very well. (Streaming video and browsing the interent were usually fine though because they are much more transactional.)
  • At first, I thought this might be the return of the shitty firmware for my wifi card under Linux, as the symptoms looked basically the same. So I deleted the newer firmware, yet it didn't make a difference.
  • The first thing I actually found wrong is that I was somehow running three network managers at once: archinstall somehow enabled both iwd and systemd-network (maybe this is normal?) and then I also enabled NetworkManager because I'm pretty sure KDE needs it. At least that produced actual logs where I could deduce what was happening.
  • As a precautionary measure I also disabled some power saving features of the wifi card, and given that this is a fat-hog gaming laptop I haven't noticed much of a difference in power usage. Things seemed to work a little better after doing this.
  • But then I found yet another problem, and one I'm unsure I can solve effectively: the RTL8852BE is just bugged under Linux such that using both Bluetooth and WiFi at the same time results in totally ass performance (see the Arch Linux BBS thread). There is a better driver available in the AUR that seems to fix this for some people, but I have yet to try it and I am way to lazy to update it every time the kernel upgrades.
  • Overall though, this is the only thing that went wrong with my Arch install which did really impress me given how I'm usually told rolling releases are so unstable and stuff. My last arch install lasted two years, which is about how long an Ubuntu install can last given that major version upgrades are still a pain there afaik and then you also get out of date software in the meantime. And my arch install probably would have happily kept chugging if I was ok with the jank of it.
